# 미션 3 제출 준비 현황

미션: AI가 계산하는 방식을 흉내 내는 작은 계산기 만들기

## 로컬 완료

- Python 3.8+ 호환 문법, 표준 라이브러리만 사용
- 3×3 직접 입력과 행 단위 검증·재입력, 필터 저장 확인
- 크기별 Matrix 값 저장/조회, 이중 반복문 MAC
- 제공 JSON의 키/크기/유한 숫자/라벨 검증과 케이스 단위 오류 보고
- Cross/X 정규화, abs 차이 < 1e-9 동점 기준
- 3/5/13/25 크기의 MAC 최소 10회(기본 30회) 반복 측정, ms 평균과 N² 출력
- 콘솔 전체/통과/실패 합계와 실패 케이스·사유
- 실제 데이터 6개 중 3 PASS/3 FAIL의 동점 원인 보고, 측정 표와 O(N²) 분석 18항
- 자동 테스트 15개 통과 및 실행 증거
- 첨부 data.json 원본과 SHA-256 보존 확인
- 선택 과제: 홀수 크기 Cross/X 패턴 생성기

## 외부 등록 상태

GitHub 저장소 생성·업로드와 코디세이 미션 시작/프로젝트 URL 등록은 아직 수행하지 않았습니다. 진행 중 Windows 잠금 화면이 관찰되어 화면 조작을 중단했습니다.

잠금 해제 후 별도 `codyssey-mini-npu` 저장소를 생성하여 main을 push하고, 미션 3의 프로젝트 URL 및 main 브랜치를 저장해야 합니다. 미션 2의 codyssey-quiz는 변경하지 않습니다.

AI 사전평가와 동료평가 결과는 아직 없습니다. 데이터 분석 결과의 3 FAIL과 과제 요구사항 평가 점수는 서로 다른 개념입니다. 제공된 데이터의 동점을 정해진 정책으로 보고한 결과이며, FAIL을 숨기기 위해 입력을 변경하지 않았습니다.
